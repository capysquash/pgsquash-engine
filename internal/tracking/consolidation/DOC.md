# internal/tracking/consolidation package map

## Domain Summary
- Contains every consolidation rule that operates on tracked object lifecycles (tables, columns, enums, functions, policies, publications, transactions, external dependencies).
- Each file implements `ConsolidationRule` plus helper utilities; rules are registered through `registry.go` and invoked by the consolidation engine in priority order.

## Files (alphabetical)

### advanced_column_lifecycle_rule.go
- **Purpose**: Handles complex column evolution (rename + type/default/constraint changes) and emits optimized CREATE TABLE statements with detailed reports.
- **Functions / Methods**
  - Rule contract: `NewAdvancedColumnLifecycleRule`, `CanApply`, `Apply`, `Risk`.
  - Column state builders: `buildColumnLifecycleMap`, `processAlterOperation`, `parseAlterOperations`, `processAddColumn`, `processDropColumn`, `processRenameColumn`, `processChangeType`, `processDefaultChange`, `processNullabilityChange`, `processConstraintChange`.
  - Constraint parsing: `parseConstraintDefinition`, `extractConstraintDefinition`, `isSQLKeyword`.
  - Pattern discovery: `identifyComplexPatterns`, `identifyRenameChains`, `identifyTypeEvolutionChains`, `identifyConstraintEvolution`.
  - SQL generation & reporting: `generateAdvancedSchema`, `buildFinalColumnList`, `generateOptimizedCreate`, `buildColumnDefinition`, `generateOptimizationReport`, `isAdvancedColumnOperation`, `extractInitialColumns`, `extractDefaultValue`, `extractTableName`, `estimateLinesSaved`.

### column_evolution_rule.go
- **Purpose**: Merges simple ALTER COLUMN sequences into concise definitions.
- **Functions / Methods**
  - Rule contract: `CanApply`, `Apply`, `Risk`.
  - Evolution analysis: `analyzeColumnEvolution`, `extractColumnChange`, `parseAddColumn`, `parseDropColumn`, `parseAlterColumn`.
  - Output helpers: `generateFinalSchema`, `isColumnOperation`.

### conditional_schema_rule.go
- **Purpose**: Preserves conditional schema operations (e.g., `IF EXISTS`/`IF NOT EXISTS`) when safety level requires.
- **Functions / Methods**
  - Rule contract: `CanApply`, `Apply`, `Risk`.
  - Helpers: `analyzeFinalConditionalState`, `generateConditionalSQL`.

### create_alter_rule.go
- **Purpose**: Integrates ALTER statements back into original CREATE statements when safe.
- **Functions / Methods**
  - Rule contract: `CanApply`, `Apply`, `Risk`.
  - Merge helpers: `integrateAlterIntoCreate`, `extractColumnFromAddStatement`, `extractConstraintFromAddStatement`, `extractColumnName`, `integrateColumnsAndConstraintsIntoCreate`, `integrateAlterTypeIntoCreate`.
  - Utilities: `parseEnumValuesFromSQL`, `containsValue`.

### dead_code_rule.go
- **Purpose**: Removes dead code objects detected by lifecycle tracking while respecting risk levels.
- **Functions / Methods**
  - Rule contract: `CanApply`, `Apply`, `Risk`.
  - Analysis helpers: `analyzeObjectUsage`, `isFunctionReferenced`.

### do_block_enum_rule.go
- **Purpose**: Normalizes ENUM modifications embedded in DO blocks.
- **Functions / Methods**
  - Rule contract: `CanApply`, `Apply`, `Risk`.

### drop_create_rule.go
- **Purpose**: Consolidates DROP + CREATE cycles while preserving constraints/columns.

  - Rule contract: `CanApply`, `Apply`, `Risk`.

- **Functions / Methods**

  - Helper: `generateOptimizedTransactionsFromPlan` - Generates SQL from TransactionPlan.
