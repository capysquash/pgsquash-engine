# internal/plugins/prisma package map

## Domain Summary
- Provides Prisma ORM integration: recognizes Prisma migrate artifacts, consolidates metadata tables/enums/indexes, injects compatibility SQL, and preserves Prisma-specific comments during squashing.

## Files (alphabetical)

### consolidation.go
- **Purpose**: Consolidation rules that merge Prisma migration tables, enum definitions, and index statements.
- **Functions / Methods**
  - `(*PrismaPlugin) GetConsolidationRules()`: Registers table/enum/index rules using local predicates.
  - `(*PrismaPlugin) canMergePrismaTables(statements)`: Detects Prisma metadata table patterns and ensures merge safety.
  - `(*PrismaPlugin) mergePrismaTables(statements)`: Produces unified CREATE TABLE preserving primary keys, indexes, and JSON columns.
  - `(*PrismaPlugin) hasPrismaComment(sql)`: Identifies Prisma migrate comment blocks used for metadata.
  - `(*PrismaPlugin) canMergePrismaEnums(statements)`, `mergePrismaEnums`: Collapse duplicate enum definitions while keeping labels.
  - `(*PrismaPlugin) canMergePrismaIndices(statements)`, `mergePrismaIndices`: Simplify index statements generated by Prisma.

### prisma.go
- **Purpose**: Core plugin implementation controlling detection, initialization, pattern reporting, preservation, and schema validation.
- **Key Types**
  - `PrismaPlugin`: Extends `plugins.BasePlugin`, stores feature flags (shadow database usage, generated metadata tables) and configuration knobs.
- **Functions / Methods**
  - Lifecycle: `NewPrismaPlugin`, `Detect`, `Initialize`.
  - Statement helpers: `EnrichStatement` (adds Prisma-specific metadata) and `isShadowDatabaseOperation` (detects shadow DB cleanup).
  - Pattern discovery: `DetectPatterns` surfaces warnings about shadow database statements, metadata tables, or comment directives.
  - Platform wiring: `GetConflictingPlugins`, `GetRequiredExtensions`, `ShouldPreserve`, `ValidateSchema`.

### transformations.go
- **Purpose**: SQL rewrites and compatibility emitters that preserve Prisma migrate semantics.
- **Functions / Methods**
  - `TransformSQL`: Top-level transformer invoking local helpers.
  - `preservePrismaComments`: Retains Prisma migrate comment markers around statements.
  - `optimizeVarcharLength`: Adjusts generated VARCHAR sizes to avoid redundant diffs.
  - `InjectCompatibilityLayer`: Emits compatibility SQL for Prisma metadata tables/functions.
  - `FixFunctionVolatility`: Marks helper functions with correct volatility.
  - `GeneratePrismaMetadata`: Constructs metadata insert statements consumed by migrations.
  - `ExtractPrismaComment`: Parses action/target info from Prisma comment directives.
  - `IsPrismaGeneratedSQL`: Heuristic for identifying Prisma-crafted files.
