# internal/plugins/drizzle package map

## Domain Summary
- Adapts Drizzle ORM migrations: detects generated artifacts, normalizes identity/sequence statements, injects compatibility SQL, and preserves metadata tables during consolidation.

## Files (alphabetical)

### consolidation.go
- **Purpose**: Registers consolidation rules tailored to Drizzle metadata tables and identity sequences.
- **Functions / Methods**
  - `(*DrizzlePlugin) GetConsolidationRules()`: Returns table and sequence rules backed by local predicates.
  - `(*DrizzlePlugin) canMergeDrizzleTables(statements)`: Verifies statements belong to Drizzle's metadata table and are merge-safe.
  - `(*DrizzlePlugin) mergeDrizzleTables(statements)`: Emits a single CREATE TABLE preserving primary keys, constraints, and default expressions.
  - `(*DrizzlePlugin) canMergeDrizzleSequences(statements)`: Ensures identity sequence statements share target identity column metadata.
  - `(*DrizzlePlugin) mergeDrizzleSequences(statements)`: Produces canonical identity sequence SQL with consistent increment/start clauses.
  - `(*DrizzlePlugin) PreserveIdentityColumns(stmt)`: Flags statements that must be kept verbatim to protect identity semantics.

### drizzle.go
- **Purpose**: Core plugin implementation responsible for detection, initialization, pattern extraction, and schema validation.
- **Key Types**
  - `DrizzlePlugin`: Embeds `plugins.BasePlugin`, tracks detection flags, and caches identity column metadata.
- **Functions / Methods**
  - Lifecycle: `NewDrizzlePlugin`, `Detect`, `Initialize`.
  - Statement enrichment/pattern helpers:
    - `EnrichStatement`: Annotates statements with Drizzle-specific metadata consumed by consolidation.
    - `hasIdentityColumn`: Checks raw SQL for identity column declarations.
    - `DetectPatterns`: Emits pattern findings (shadow tables, metadata tables, identity definitions).
  - Platform integration:
    - `GetConflictingPlugins`, `GetRequiredExtensions`, `ShouldPreserve`, `ValidateSchema`.

### transformations.go
- **Purpose**: SQL rewrites and volatility fixes that normalize Drizzle-generated statements before parsing/consolidation.
- **Functions / Methods**
  - `TransformSQL`: Entry point that orchestrates identity/sequence rewrites.
  - `optimizeIdentityColumns`, `optimizeSequenceConfig`: Helpers invoked during transform to rewrite column defaults and sequence ownership.
  - `InjectCompatibilityLayer`: Emits compatibility SQL (metadata tables, helper functions) when requested.
  - `FixFunctionVolatility`: Applies STABLE/IMMUTABLE markers to Drizzle helper functions.
  - `ConvertSerialToIdentity`: Converts legacy SERIAL declarations into identity syntax.
  - `IsDrizzleGeneratedSQL`: Heuristic detection for raw SQL generated by Drizzle.
  - `ExtractIdentityType`: Parses column definitions to determine `GENERATED ALWAYS/BY DEFAULT` semantics.
